## What this chapter covers

How Linux manages identities. Creating, modifying, and deleting users and groups. The structure of `/etc/passwd` and `/etc/shadow`. The difference between `su` and `sudo`. Inspecting who is logged in and what they've done. Troubleshooting: user can't change password, user account has no home directory.
