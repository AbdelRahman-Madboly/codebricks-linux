## What this chapter covers

How Linux manages running software. `systemctl` for starting, stopping, enabling, and checking services. Reading service logs with `journalctl`. Inspecting processes with `ps`, `top`, `htop`. Killing processes cleanly and forcefully. Scheduling recurring tasks with `cron` and one-time tasks with `at`. Open file and connection inspection with `lsof`.
