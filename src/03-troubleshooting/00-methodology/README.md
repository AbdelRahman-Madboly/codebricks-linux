## What this chapter covers

How to think when something breaks. A systematic approach that works whether the problem is a dead server or a misconfigured cron job. Read logs first — never touch the system before you understand what happened. Reproduce the issue yourself. Document every step. Know when to escalate.

This is the shortest chapter and the most important one.
