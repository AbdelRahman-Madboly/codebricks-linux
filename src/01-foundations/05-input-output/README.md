## Objectives
By the end of this chapter I can:
- [ ] Connect commands with pipes (`|`)
- [ ] Redirect stdout, stderr, and stdin (`>`, `>>`, `2>`, `<`)
- [ ] Read and use exit codes (`$?`)
- [ ] Inspect and stop processes with `ps`, `top`, and `kill`
