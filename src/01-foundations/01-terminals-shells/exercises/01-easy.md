# Exercise 1: First Commands
Difficulty: Easy
Concepts: echo, whoami, shell variables, string interpolation

## Scenario
You just opened a fresh terminal on your Ubuntu machine and want to confirm that basic shell interactions work as expected.

## Your Task
1. Print your username to the terminal using a built-in command.
2. Set a variable called `project` with the value `linux-lab`.
3. Print the sentence `Working on linux-lab` using your variable — not the literal string.

## Check Your Work
The output of step 3 shows `Working on linux-lab` on screen, and no dollar sign or variable name appears in the output.
