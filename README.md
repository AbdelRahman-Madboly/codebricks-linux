# codebricks-linux

Making Linux feel like home — no more googling basic commands.

Structured by the Linux Foundation's *Open Source Software Development Methods*
(Coursera), but most of the learning happens in the terminal. Daily use builds
the muscle; the course gives the shape.

## How this repo is organized
- `src/` — my own work: `notes.md` in my words, `exercises.sh` with commands I actually ran
- `_plan/` — purpose, progress tracking, and how I use AI
  - `_plan/AIM.md` — what this repo is for and what "done" means
  - `_plan/PROGRESS.md` — honest week-by-week tracking
  - `_plan/SKILL.md` — the rules for using AI here
  - `_plan/content/` — course materials (never committed)

See [`_plan/AIM.md`](_plan/AIM.md) for the full intent and [`ROADMAP.md`](ROADMAP.md) for the plan.
