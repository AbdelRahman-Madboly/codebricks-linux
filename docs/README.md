# docs/

Written material that supports the repo. Three layers, three jobs:

| Layer | Folder / file | Use it to | Voice |
|-------|---------------|-----------|-------|
| **Study** | [`study/`](study/) | *Read and understand* a topic; revise before an interview | Prose notes |
| **Reference** | [`reference/`](reference/) | *Look something up fast* while working | Tables, checklists, command sequences |
| **Cheatsheet** | [`cheatsheet.md`](cheatsheet.md) | Grab a single command quickly | One-liners |

For *doing* (hands-on, with a tutor), go to [`../src/`](../src/) and [`../practice/`](../practice/),
driven by [`../TUTOR.md`](../TUTOR.md). For the chapter map, see [`../ROADMAP.md`](../ROADMAP.md).

## Study guides — [`study/`](study/)

Read-to-study notes, one subfolder per **finished** course. Original, generic, searchable.

- [`study/open-source-methods/`](study/open-source-methods/) — what OSS is, contributing, CI/CD,
  licensing, patents, leadership and community. Includes [interview drills](study/open-source-methods/interview-drills.md).
- [`study/linux-troubleshooting/`](study/linux-troubleshooting/) — diagnostic method plus system
  access, filesystem/storage, system admin, and recovery — the *why* and the diagnostic order.
  Includes [interview drills](study/linux-troubleshooting/interview-drills.md).

More subfolders appear here as each course is completed — see [`study/README.md`](study/README.md).

## Reference — [`reference/`](reference/)
