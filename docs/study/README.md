# Study Guides

The **read-to-study** layer of this repo: prose notes I can read, search, and revisit before an
interview. This is different from the other two layers:

| Layer | Where | Use it to |
|-------|-------|-----------|
| **Study** (you are here) | `docs/study/` | *Read and understand* a topic; revise concepts |
| **Practice** | [`src/`](../../src/) + [`practice/`](../../practice/) | *Do it hands-on*, build muscle memory with a tutor |
| **Reference** | [`docs/reference/`](../reference/) | *Look things up fast* while working |

> All study docs are my own notes in my own words — original, generic, no brand names. Each is
> meant to be greppable.

## How to study with these

1. **Read** a module doc top to bottom once — don't skim the "why it works this way" parts.
2. **Answer the "Check yourself" questions out loud.** If you can't, reread that section.
3. **Run the interview drills** cold, then connect each answer to your own real projects.
4. When you want offline/printable copies, convert the `.md` to `.docx` later (a lighter model can
   batch that — these are kept in Markdown to stay searchable and diff-friendly).
